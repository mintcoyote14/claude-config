Всі нові скрипти зберігати одразу в `D:\_SCRIPTS_` (корінь робочої папки). Не давати інструкцій зі встановлення чи користування — ні команд копіювання в `ScriptUI Panels`, ні розділу «як натискати кнопки».

**Why:** користувач запускає скрипти зі своєї власної панелі-лаунчера (`ScriptLauncherPanel.jsx`), яка читає цю папку, і сам добре знає AE — покрокові інструкції для нього шум.

**How to apply:** записав файл у `D:\_SCRIPTS_` — і у відповіді лише коротко про те, що скрипт робить і які є нетривіальні параметри/припущення. Без блоків `copy ...`, без «Встановлення», без «Як користуватися».

Якщо користувач просить інструкцію до скрипта (напр. польською для колег) — давати її **текстом у чат**, а не створювати файл README/INSTRUKCJA в папці зі скриптами. Такі файли в папках скриптів не тримаємо.
