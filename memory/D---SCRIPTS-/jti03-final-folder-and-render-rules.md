**Фінальні версії для клієнта** збираємо в `E:\JTI_03\_out\final\` (окрема папка від `_out\client\<дата>\`, де лежать драфти на погодження).
Станом на 27.11.2026: `JTI03_PV01_FINAL_EN-subs_1920x1080_no-audio.mp4` + `.srt` (проєктне відео №1 погоджене клієнтом; для трансляції на екранах — англійські субтитри, без звуку, 1920×1080).

**Версія з субтитрами** = як у тизері: `_build\make_pv01_subs.py` (репліки й таймінг із whisper по фінальному аудіо) → `data\jti03_pv01_subs.json` + SRT → `_build\31_pv01_subs.jsx` будує `JTI03_PV01_SUBS` (майстер без змін + шари SUB_nn + SUBS_BOX). Рендер лише відео (PNG, один елемент у черзі), кодування ffmpeg з `-an`. Для PV02–04 те саме: скопіювати скрипти, змінити імена/репліки.

**Why:** субтитри потрібні, коли клієнт просить версію для екранів без звуку; тизер так уже робили.

**Правило рендеру шматками:** у одному запуску черги НЕ ставити два шматки в одну папку з PNG-секвенцією — другий отримує нумерацію першого й лягає не на своє місце (у PV02–04 так з'їхали сцени, 24.11). Один шматок на папку за запуск; після рендеру звірити секвенцію з AE (`comp.saveFrameToPng` на кожній секунді проти `f_NNNNN.png`, середня різниця <3). Повні клієнтські кодування робити тільки після такої звірки.

**How to apply:** перед випуском версій перевірити кадри; PV01 музика v5 (`music\crop\JTI03_PV01_Music_only_v5.wav`) — чернетка-заглушка, справжній трек підганяє користувач у Premiere.
