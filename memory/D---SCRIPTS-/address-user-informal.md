Користувач прямо попросив: «до мене можна на ти». Усі відповіді українською на «ти».

**Why:** неформальний робочий стиль, «ви» звучить зайво офіційно.
**How to apply:** у кожній відповіді — «ти/твій», без «ви/ваш».
