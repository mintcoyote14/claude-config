# Правила для Claude

## Спілкування
- Відповідай українською, до користувача на «ти».
- Коротко: що зроблено, нетривіальні припущення. Без покрокових інструкцій, якщо їх не просили.

## Скрипти After Effects (`D:\_SCRIPTS_`)
- Новий скрипт клади одразу в `D:\_SCRIPTS_`. Копіювання в `ScriptUI Panels`, розділи «Встановлення» чи «Як користуватися» не пиши: користувач запускає скрипти з `_system\ScriptLauncherPanel.jsx`.
- Інтерфейс (вікна, кнопки, alert/confirm/prompt, helpTip, звіти) і коментарі в коді пиши англійською: файли можуть потрапити до колег.
- README та INSTRUKCJA поруч зі скриптами не створюй. Якщо потрібна інструкція (наприклад, польською для колег), дай її текстом у чат.
- Файли зберігай у UTF-8 з BOM.
- Частину скриптів Biedronka користувач веде в іншій сесії Claude Code. Перед правкою перечитуй файл з диска, чужі зміни не відкочуй і не «виправляй» без прохання.

## Разові задачі: слот `D:\_SCRIPTS_\!TASK.jsx`
1. Скопіюй поточний файл у `_task_archive\YYYY-MM-DD_коротка-назва.jsx`.
2. Міняй лише блок `task()`, рядок `// TASK:` і `// DATE:`. Обгортку (undo-група, catch, `__CANCEL__`, хелпери) не чіпай.
3. Збережи з BOM.

## After Effects MCP
- Зберігай проєкт після кожного логічного кроку (`ae_save_project`).
- Рендер: лише став у чергу й перевір шляхи та тривалість. `render.start` не викликай, кнопку Render тисне користувач сам. Виняток: він прямо сказав «запускай рендер». Другий виняток: однокадрові PNG візок при перенесенні в новий тиждень, коли всі шляхи пишуть у сьогоднішній output (деталі в скілі Biedronka, `references/carry-over.md`).
- Перевіряй результат рендером кадру, а не на око.
- Не вгадуй невідоме правило: спитай.

## Складання спотів Biedronka
Усі правила лежать у скілі `D:\_SCRIPTS_\.claude\skills\biedronka-spot-assembly\`, він підключається автоматично. Головне:
- Працюй у `W<NN>\compo\_ai_progress\`. У самому `compo` лишаються тільки затверджені проєкти спотів.
- Існуючий файл у `compo` без явної згоди не перезаписуй.
- Перед великою правкою роби резервну копію в `_ai_progress\_backup\`.
- Пісочниця `…\vfx\temp\AI_TEST\` лише для навчання та читання чужих проєктів.
- Монтаж по голосу робить користувач.
- Усі папки (і файли, що створюю я) в проєктах називай латиницею без польських діакритичних знаків (`Losos`, не `Łosoś`).

## Безпека
- **Диск X: це сервер компанії. Поводься з файлами максимально обережно:** не допускай, щоб файли випадково видалилися, зникли чи зіпсувалися. Перед видаленням, перейменуванням, перезаписом чи переміщенням подивись, що там лежить; видаляй лише те, що сам щойно створив або що користувач прямо назвав; без масових `-Recurse`-операцій; резерв перед змінами; після копіювання звіряй MD5; при сумніві питай.
- Не видаляй і не перезаписуй файли в робочих проєктах без згоди. Перед правкою подивись, що там зараз.
