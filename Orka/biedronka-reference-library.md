# Biedronka — reference library (all boards)

Registry of every reference Artem has put on a Magnific board for Biedronka work: node name, what it shows, where the file came from, which board/project used it. Purpose: each new project starts on an empty board — when a scene needs a reference that isn't on the new board yet, look here first and tell Artem which node from which past board to bring over (by board name).

**Master folder: `D:\_AI_` on Artem's computer** — always contains the current store look (store photos 01–022, 014_01) and the bag (`torba_v001`–`v005`); Artem adds further references used on boards there. When the folder is connected, list it at the start of a project and log any file not yet in this library. Node names on a board = filenames unless Artem says otherwise. **Before picking a store photo, check this table (verified by viewing the photos), not older notes.**

**Board naming:** `<project> AP <number>` — project name, Artem's initials, running number (e.g. `Torba AP 01`). Ask for the name when a new board starts.

**Updating from any session:** every session working on a Biedronka board reads this file first, then adds its own board's nodes (name, what it shows, source, scenes) and moves "Boards" status. Read → merge → write the full file back; never drop rows other sessions added.
